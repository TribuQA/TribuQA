## Prompt 1: Instalación de Java 17 en Windows 10 (Oracle, archivo comprimido)

**Contexto:**  
Consulta para obtener instrucciones sobre la instalación manual de Java 17 (archivo comprimido de Oracle) y su configuración en las variables de entorno de Windows, estableciendo el path en `C:\recursos`.

```prompt
Actúa como un experto en administrador de sistemas. 
 
La notebook que uso tiene como sistema operativo Windows 10 de 64 bits.
 
¿Cómo instalo java versión 17 (archivo comprimido) del distribuidor oracle y luego como lo agrego en las variables de entorno? ¿Quiero que el path de java sea C:\recursos?
```

## Prompt 2: Instalación de Maven 3.8.6 y configuración de variables de entorno

**Contexto:**
