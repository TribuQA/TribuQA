# 👋 ¡Bienvenido a **TribuQA**!

![Visitors](https://visitor-badge.laobi.icu/badge?page_id=TribuQA.TribuQA&left_color=0F2027&right_color=007ACC&left_text=🌍%20Visitas%20a%20TribuQA)

**TribuQA** es una startup que combina **formación técnica, consultoría** y el uso de **IA** para acelerar el aprendizaje y la implementación de soluciones en testing automatizado.

🚀 Queremos que iniciarse en el mundo del QA no sea lento ni complejo.  
Por eso aplicamos **tecnologías punteras** y **herramientas de Inteligencia Artificial (ChatGPT, Copilot, etc.)** para aprender más rápido, automatizar más y trabajar mejor.

---

## 🌐 Laboratorio de APIs

> 🔍 **Experimentá. Practicá. Automatizá.**

El **Laboratorio de APIs de TribuQA** es un entorno diseñado para que practiques pruebas reales con **APIs y GPTs listos para usar**, siguiendo **buenas prácticas de automatización** y flujos propios de un **QA Automation moderno asistido por IA**.

⚙️ Ideal para:
- Entrenar tus skills de QA automation con las APIs REST desplegadas.  
- Probar estrategias de validación automatizada.
- Analizar buenas prácticas con los contratos Swaggers disponibles. 
- Usar GPTs especializados como asistentes de QA (en progreso de desarrollo).
